Optional AI layer

Off

The app works fully without this. When enabled, it can improve tag extraction and write richer collaboration proposals using your own API key. Your key is stored only in this browser and is sent only to the provider you choose.

Live funding search

Off

Off by default. When enabled, the Find Funding tab sends a scholar's top research terms — not their CV text — to Grants.gov's public search API to look up matching open opportunities. Results are cached on this device to avoid repeat queries.

This app has no server of its own, so this call is made directly from your browser. If your browser blocks it (a cross-origin restriction), the Find Funding tab falls back to a link that opens grants.gov's own search in a new tab, with the same terms, so the feature degrades rather than silently failing.

PDF & data

PDF text extraction

Built-in extraction works offline for most digital PDFs. Scanned or unusual PDFs may extract poorly; for those, paste the text or enable enhanced parsing (loads pdf.js from a CDN, so it needs a network connection).

Appearance

About

Grant Crosswalk is a self-contained progressive web app. All CV parsing and analysis run locally in your browser; nothing is uploaded unless you explicitly enable the optional AI layer. Built as an installable PWA: use your browser's Install option to add it to your machine and run it offline.
